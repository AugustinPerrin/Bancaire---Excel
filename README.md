# Bancaire---Excel
Scrapper et organisateur des données de relevés bancaires en Excel. Identification des données, triage automatique et manuel des données en catégories. Mise en Forme. Analyse sur les données organisées. 
Ce projet interface python et VBA pour mieux gérer ses synthèses bancaires.

Le dossier est composé de : 
  Un dossier python, comportant une classe et une BDD, et un script appelé par une macro dans le fichier Excel  
  Un fichier Excel, comportant une macro appelant le script python avec des paramètres, et une macro de mise en page des données récupérées.
